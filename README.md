#  Sistema de Gestión Bancaria 🏦

Proyecto académico desarrollado en equipo para la UTN FRGP. Aplicación web en Java que permite simular el funcionamiento de un banco, con funcionalidades tanto para administradores como para clientes.

---

##  Funcionalidades
- Registro e inicio de sesión de usuarios
- Roles: Administrador y Cliente
- Autorización/Rechazo de préstamos solicitados
- Generación automática de cuotas para préstamos aprobados
- Reportes estadísticos con filtros por fecha
- Consulta de movimientos por cuenta
- Transferencias entre cuentas propias o de terceros (por CBU)
- Solicitud de préstamos
- Pago de cuotas de préstamos (con registro de fecha)

---

##  Tecnologías y conceptos utilizados
- Java
- JSP / Servlets / JDBC
- MySQL
- Trabajo colaborativo en equipo
